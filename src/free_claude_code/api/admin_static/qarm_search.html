البحث الذكي والمتخصص

ابحث عن شيء محدد، احصر النتائج بموقع معين، واقرأ مقتطفات من المصادر في وضع البحث المعمّق. لا تحتاج مفتاح API أو بطاقة بنكية.

كيف يعمل البحث؟ يرسل قرم عبارة البحث إلى DuckDuckGo ويعرض روابط المصادر. إذا اخترت البحث المعمّق، يحاول فتح أول ثلاثة مصادر عامة لعرض جزء من محتواها. لا يجري حاليًا تلخيصًا بالذكاء الاصطناعي، ولا تُعد مقتطفات المواقع حقائق موثقة قبل التحقق منها. قد ترفض بعض المواقع فتح محتواها أو تحجب البحث الآلي. ولا يستخدم قرم مزودًا مدفوعًا بدلًا منها تلقائيًا.
