# نشر قرم بحساب Render مجاني

هذه الملفات تحضّر تطبيق قرم للنشر على Render Free، دون اشتراك أو بطاقة. لم يتم إنشاء خدمة Render أو نقل المفاتيح بعد.

- إعداد `plan: free` صريح؛ لا توجد قاعدة بيانات مدفوعة أو قرص مدفوع أو استدلال GPU مدفوع.
- تستخدم الصور عروض Hugging Face ZeroGPU العامة فقط؛ يتوقف الطلب عند انتهاء الحصة ولا يتحول إلى خدمة مدفوعة.
- تحفظ مفاتيح Groq وكلمة مرور المالك في Secrets عند Render؛ لا تضفها إلى GitHub أو Dockerfile أو المحادثة.
- يمنع السكربت التشغيل دون كلمة مرور مالك قوية ومفتاح Groq، ويحمي واجهات البرمجة بمفتاح داخلي كذلك.
- افتح `/admin/qarm/chat` بعد النشر. تتوفر واجهة متجاوبة وصور وبحث ومساحة برمجة.

## ما توفره الاستضافة المجانية وما يتغير

ينام Render Free بعد 15 دقيقة من عدم الاستخدام، ويستيقظ تلقائيًا عند فتح الرابط؛ قد تستغرق العودة نحو دقيقة. لا يحتاج بقاء الكمبيوتر مشغّلًا. ينتهي وصول الخدمة مؤقتًا إذا استُهلكت الحصة الشهرية؛ لا نضيف وسيلة دفع.

بيئة Render Free لا تحفظ الملفات المحلية عند النوم أو إعادة النشر. **محادثات المتصفح تبقى إذا فعّلت الحفظ على الجهاز، لكن ملفات جلسات البرمجة والصور الموجودة على الخادم قد تضيع.** لا تنقل مشاريعك الأساسية إليه قبل إضافة تخزين دائم مناسب ومجاني والتحقق منه. نسخة Codespaces الحالية تبقى متاحة، ولا تُحذف إعداداتها أو مشاريعها.

التوصية لهذا الإصدار: Render للوصول إلى المحادثة والصور والبحث من رابط مستقل؛ حافظ على مشاريع البرمجة في GitHub واحفظ الصور التي تحتاجها على جهازك. لا يوجد في هذه الملفات ضمان استضافة 24/7 أو تخزين دائم مجاني.
